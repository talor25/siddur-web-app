# 📖 סידור עדות המזרח – אפליקציית תפילה דינמית

אפליקציית Web מודרנית, נגישה ורספונסיבית לתפילות בנוסח עדות המזרח, בעלת מצבי הלכה דינמיים המותאמים בזמן אמת לעונות השנה ולימים מיוחדים.

> הפרויקט פותח במסגרת **משימת סוף קורס: הכרות עם כלי בינה מלאכותית** (המכללה למינהל).

## ✨ תכונות מרכזיות (Features)

1. **תפילות מלאות בנוסח עדות המזרח**:
   * שחרית לחול (כולל ברכות השחר, ציצית ותפילין, פסוקי דזמרה, קריאת שמע, עמידה, וידוי ותחנון, אשרי ובא לציון, שיר של יום, קווה, עלינו לשבח).
   * תפילת מנחה.
   * תפילת ערבית.
   * ברכת המזון.
   * בורא נפשות.
   * ברכת הלבנה.

2. **מצבי הלכה דינמיים**:
   * **בורר עונות (קיץ / חורף)**: זיהוי אוטומטי של עונת השנה והחלפת נוסח ברכת השנים (ברכנו / ברך עלינו) וברכת מחיה המתים (טל / גשם).
   * **בורר עשרת ימי תשובה**: הצגה/הסתרה של תוספות עשי"ת (זכרנו לחיים, המלך הקדוש, המלך המשפט ועוד).

3. **ניווט מתקדם ורספונסיבי**:
   * **עיצוב מובייל תחילה (Mobile-First)**: התאמה מלאה לסמארטפונים, טאבלטים ומחשבים.
   * **תפריט תוכן עניינים דינמי (Dropdown TOC)**: לחיצה על אייקון `📖` בכותרת העליונה פותחת תפריט ניווט מהיר לגלילה חלקה לקטעי התפילה.
   * **שיר של יום דינמי**: זיהוי יום השבוע בשעון המכשיר והצגת המזמור המתאים באופן אוטומטי.

4. **נגישות וחווית משתמש (UI/UX)**:
   * **מצב לילה / יום (Dark Mode / Light Mode)** למניעת סינוור בתפילות חשיכה.
   * **בקרת גודל גופן (א+ / א-)** להגדלה והקטנה של הכתב בזמן אמת.
   * **שמירת העדפות מקומית** ב-`localStorage`.

---

## 🛠️ טכנולוגיות (Tech Stack)

* **HTML5**: מבנה סמנטי מונגש.
* **CSS3**: עיצוב Vanilla רספונסיבי, Flexbox, משתני CSS (`--variables`), מצב כהה ועיצוב ספר קודש פרימיום.
* **JavaScript (ES6+)**: לוגיקת Single Page Application (SPA), ניהול State, מנגנון הראוטינג (`hashchange`), וטעינת נתונים מודולרית.
